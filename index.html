How it works

01
⚙️
Create
A contributor ships a vulnerable machine — defined entirely in code (Vagrant + Docker). No binary blobs.
02
🔴
Red Team
Players download the VM and try to capture the root flag. Submit a writeup + exploit script via Pull Request.
03
🩸
Reveal
First Blood unlocks the source code. The exploit is locked as the regression test for all future patches.
04
🔵
Blue Team
Defenders fork the source, patch the root cause, and submit via PR. The CI replays the exploit — it must fail.

Why BreachToPatch

🐝 GitHub-native

Every pwn and every patch is a public Pull Request. Your contributions build your GitHub profile — a real asset for cyber recruiters.

⚔️ Double-edged exploits

The exploit you submit becomes the automated regression test that validates every future patch. Attack and defense are intertwined.

💾 Infrastructure as Code

Machines are plain text files — Vagrant, Ansible, Docker Compose. No huge .ova files. Versionable, forkable, auditable.
